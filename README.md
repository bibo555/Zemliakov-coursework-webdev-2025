# Airline Booking System — Веб-приложение бронирования авиабилетов

Веб-приложение на Flask для поиска, бронирования авиабилетов и управления учетными записями пользователей, паспортами и рейсами. В проект встроена административная панель для работы с пользователями и билетами, а также система автоматической инициализации тестовых данных.

## Стек технологий

* **Фреймворк:** Flask 2.3.2
* **Аутентификация и сессии:** Flask-Login 0.6.2
* **База данных и миграции:** Flask-SQLAlchemy 3.0.5, Flask-Migrate 4.0.4, SQLAlchemy 2.0.19, Alembic 1.11.1
* **Конфигурация:** python-dotenv 1.0.0
* **Шаблонизатор:** Jinja2 3.1.2
* **Поддерживаемые СУБД:** SQLite (по умолчанию), PostgreSQL

## Основные возможности

* **Аутентификация и авторизация:** Регистрация, вход в систему и разграничение прав доступа (пользователь и администратор).
* **Административная панель:**
  * Просмотр списка зарегистрированных пользователей, их паспортов и бронирований.
  * Безопасное удаление пользователей и связанных с ними записей.
  * Управление рейсами и билетами: просмотр, добавление новых направлений, редактирование и удаление.
* **Поиск и бронирование билетов:** Хранение данных о маршрутах, времени вылета/прилета, аэропортах вылета/назначения, стоимости и длительности полета.
* **Управление паспортами:** Поддержка привязки серии, номера, кем выдан и даты выдачи паспорта к профилю пользователя.
* **Загрузка файлов:** Поддержка загрузки аватаров профиля и сканов документов (поддерживаемые форматы: `png`, `jpg`, `jpeg`, `gif`, `pdf`, лимит размера: 16 МБ).
* **Инициализация данных:** Автоматическое наполнение базы данных аэропортами (SVO, DME, LED и др.), авиакомпаниями (Aeroflot, S7 и др.), тестовыми рейсами и администратором.
